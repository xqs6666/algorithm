
## 🧱 一、普通卷积网络的问题：越深越学不会

假设我们有一个普通卷积网络：

```
输入 x → Conv → ReLU → Conv → ReLU → 输出 y
```

如果我继续加层：

```
x → Conv1 → Conv2 → Conv3 → Conv4 → Conv5 → y
```

理论上层数越多应该更厉害，但实验发现：

> 当网络层数太多（比如 > 30 层）时，训练集准确率反而下降！

原因：

* 梯度在反向传播时逐层变小（**梯度消失**）。
* 网络学不到“恒等映射”（就是“别动输入”这种简单功能）。

---

## ⚙️ 二、ResNet 的关键点：**“不去掉旧信息”**

假设有一层卷积学不好怎么办？
ResNet 说：

> “那我不强迫这一层学所有东西，我让它只学**变化的部分**。”

于是提出了一个公式：

$$
y = F(x) + x
$$

这就是“残差（Residual）”的意思：

* ( F(x) )：当前层学到的新特征（差异部分）
* ( x )：上一层的结果（原始特征）
* ( F(x) + x )：合并后的输出（原+新）

---

## 🧩 三、为什么 “+x” 这么重要？

我们用一个生活类比👇

| 情景     | 解释                  |
| ------ | ------------------- |
| 普通网络   | 像老师让你从零开始重写作文       |
| ResNet | 老师让你在旧作文上改进（只改错的地方） |

显然——“改错”比“重写”简单多了。
这就是为什么残差结构更容易优化。

---

## 📈 四、数学层面看梯度

普通网络反向传播时：
$$
\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \cdot \frac{\partial y}{\partial x} = \frac{\partial L}{\partial y} \cdot F'(x)
$$

如果 ( F'(x) ) 很小（比如 0.1），梯度会越来越小。

但在 ResNet 中：
$$
y = F(x) + x \Rightarrow \frac{\partial y}{\partial x} = F'(x) + 1
$$

即使 ( F'(x) = 0 )，梯度也能直接通过“+1”流回去。
👉 **梯度不会消失！**

## 🔩 五、残差块结构图（ResNet 的“最小单元”）

```
      ┌─────────────┐
x ───►│ Conv3x3 + BN│
      └───────┬─────┘
              ▼
         ReLU激活
              ▼
      ┌─────────────┐
      │ Conv3x3 + BN│
      └───────┬─────┘
              ▼
       ┌────────────┐
       │   相加 (+x) │ ←─── 原始输入x（捷径）
       └──────┬─────┘
              ▼
           ReLU输出 y
```

📌 意思是：卷积模块学“差值”，输入直接绕过后加回来。

## 🧠 六、PyTorch 里对应代码逻辑

```python
class BasicBlock(nn.Module):
    def __init__(self, channels):
        super().__init__()
        self.conv1 = nn.Conv2d(channels, channels, 3, padding=1)
        self.bn1 = nn.BatchNorm2d(channels)
        self.conv2 = nn.Conv2d(channels, channels, 3, padding=1)
        self.bn2 = nn.BatchNorm2d(channels)

    def forward(self, x):
        identity = x             # 捷径保存
        out = F.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out = out + identity     # 残差相加
        out = F.relu(out)
        return out
```

每个 `BasicBlock` 都是一个“小修正单元”，整个 ResNet 就是堆叠很多这样的块。

## 🧮 七、尺寸变化时怎么办？

当某个残差块输入输出通道数不一样（比如从 64 → 128）时，
我们就让捷径也“变一下形”：

```python
downsample = nn.Conv2d(64, 128, kernel_size=1, stride=2)
```

让它维度对齐后再加：
$$
y = F(x) + W_s x
$$

ResNet、VGG、甚至几乎所有现代卷积神经网络里都有 **BN 层（Batch Normalization）**，
它是深度学习里一个非常核心的“稳定训练神器”。

---

## 🧠 一、BN 是什么？

BN 全称是 **Batch Normalization**，
中文叫 **批量归一化 / 批标准化**。

它的目的很简单：

> 让每一层的输入数据都保持“分布稳定”，不会乱跑。

---

## 📉 二、为什么需要 BN？

我们先看一个问题：
在神经网络中，每一层的输入都是前一层的输出。

但随着训练进行，前一层的参数在不断更新，
导致下一层看到的输入分布也在变，这叫：

> 🌀 **内部协变量偏移（Internal Covariate Shift）**

这会让训练：

* 不稳定（梯度爆炸或消失）
* 学习速度慢
* 要小心调学习率、初始化等参数

BN 的作用就是：

> 把每一层的输入“拉回到正常范围”，
> 例如平均值接近 0、方差接近 1。

---

## 🔢 三、BN 的数学原理

假设某层输入为 ( x = $$x_1, x_2, ..., x_m$$ )，
其中 ( m ) 是 batch 的样本数。

BN 的步骤如下👇：

### 1️⃣ 计算当前批次的均值与方差

$$
\mu_B = \frac{1}{m} \sum_{i=1}^m x_i
$$
$$
\sigma_B^2 = \frac{1}{m} \sum_{i=1}^m (x_i - \mu_B)^2
$$

### 2️⃣ 进行标准化

$$
\hat{x_i} = \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}
$$
这一步让 ( \hat{x} ) 的均值=0，方差=1。

### 3️⃣ 加入可学习的缩放和平移参数

$$
y_i = \gamma \hat{x_i} + \beta
$$
其中：

* ( \gamma )：可学习的缩放参数（scale）
* ( \beta )：可学习的平移参数（shift）

这样 BN 不会强制数据一定要“标准正态”，
而是允许网络自己学最合适的分布。

## ⚙️ 四、BN 在 PyTorch 里的实现

PyTorch 已经封装好了：

```python
import torch.nn as nn

# 对卷积层输出使用 BN
layer = nn.Sequential(
    nn.Conv2d(64, 64, 3, padding=1),
    nn.BatchNorm2d(64),  # 对每个通道做标准化
    nn.ReLU()
)
```

> 对于全连接层（MLP），用 `nn.BatchNorm1d()`。
> 对于卷积层（CNN），用 `nn.BatchNorm2d()`。

---

## 🧩 五、BN 放在什么位置？

在卷积神经网络中，一般放在：

```
卷积层 → BN → ReLU
```

例如 ResNet 的残差块：

```python
out = self.conv1(x)
out = self.bn1(out)
out = F.relu(out)
```

| 🚀 加快收敛     | 可以用更大学习率    |

| 🧩 有轻微正则化效果 | 降低过拟合       |

## 🎯 七、举个直观例子

假设一层输出值特别大（平均值 100，方差很大），
下一层激活函数可能饱和（比如 ReLU 全是正数），
导致梯度几乎传不回去。

BN 把这层的输出“拉回来”成均值≈0、方差≈1，
于是激活函数仍然在“有效区间”，网络继续能学。

> 让信号不过强不过弱，稳定地流动整个网络。
